Usei o padrão Adapter porque ele é um tradutor. O exercício deu uma interface nova, "limpa", mas me forçou a usar um sistema antigo e "confuso" que fala um "idioma" diferente (com HashMap). O Adapter foi a ponte que criei no meio: ele recebe a chamada nova, traduz pro formato antigo, chama o legado, e depois traduz a resposta antiga de volta pro formato novo. Assim, o sistema novo nem sabe da bagunça do antigo.
